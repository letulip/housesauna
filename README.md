# This is HouseSauna repo

Consists of all back end files.

## Installation

1. Fork on Github
2. git clone git@github.com:YOUR-PROFILE/housesauna.git on terminal
3. python3 -m venv venv
4. source venv/bin/activate
5. python3 manage.py runserver


Описание фичи с добавлением фото к объекту через админку:
- переименование фото происходит автоматически на `короткий тег объекта + номер по порядку загрузки с 0 + .jpeg`
- на сервере сохраняются в медиа, не в статике
- порядок при добавлении выставляется автоматически (как добавили, так и выставится)
- первая фото в списке с -0 именем автоматически становится обложкой
- фотографии добавляются по одной в одно окошко (специфика джанго), так что нужно нажать `Add another Фото бани` столько раз, сколько нужно загрузить фото, и в каждую форму добавлять следующую фотку
- если случайно загружена повторка - просто удалите ее и все. Путей вручную больше нет, так что цикл показа не собьется.
